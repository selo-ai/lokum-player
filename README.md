# Lokum Media Center 🍬📺

Lokum Media Center is a modern, premium, and fast IPTV player built with Flutter. It aims to provide a seamless and visually stunning experience for watching Live TV, Movies, and Series.

## Features

- **Sleek UI/UX**: Glassmorphism design elements, smooth animations, and a modern dark theme.
- **Categorized Content**: Smart categorization and filtering (e.g., country-based accordion grouping for Live TV).
- **Fast & Responsive**: Built with Flutter for high performance across platforms.
- **Favorites System**: Easily bookmark your favorite channels, movies, and series.

## Tech Stack

- **Framework**: Flutter / Dart
- **State Management**: Riverpod
- **Video Player**: `media_kit` (for robust, high-performance playback)
- **Architecture**: Modular and maintainable structure

## Getting Started

1. Clone the repository: `git clone https://github.com/selo-ai/lokum-player.git`
2. Fetch dependencies: `flutter pub get`
3. Run the app: `flutter run`
